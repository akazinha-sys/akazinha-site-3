# AKAZinha.wav — Home

Primeira versão da Home da AKAZinha.wav, inspirada no layout preto/branco criado no briefing.

## Rodar localmente

Requer Node.js 20+.

```bash
npm install
npm run dev
```

Abra http://localhost:3000

## Onde colocar suas fotos

Substitua os blocos visuais em `app/page.tsx`/`app/globals.css` por fotos reais quando quiser.

Pastas reservadas:
- `public/studio/` — fotos do estúdio
- `public/releases/` — capas dos lançamentos
- `public/instagram/` — imagens para a grade social

O logo fornecido no briefing foi recortado para fundo transparente e está em `public/logo-z.png`.

## Próxima etapa recomendada

1. Colocar fotos reais do estúdio.
2. Cadastrar os lançamentos reais.
3. Integrar Spotify/YouTube.
4. Criar páginas individuais para cada lançamento.
5. Configurar domínio `akazinha.com` na hospedagem.
6. Adicionar SEO, favicon e analytics.
